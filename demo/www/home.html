Tiny 웹 서버 데모

이 페이지는 우리 팀이 C로 만든 웹 서버가 demo/www/ 폴더에서 보내고 있습니다.

개발자 도구 → Network 탭 → "Disable cache"를 켜고 보세요.

1 정적 파일: 파일 종류(MIME)를 맞게 보내는가

파일Network 탭에서 볼 Content-Type맞으면 보이는 것
home.htmltext/html이 페이지
style.csstext/css글꼴, 테두리, 색
app.jstext/javascript❌ JS가 실행되지 않음
crying_cat.jpgimage/jpeg아래 고양이

2 CGI: 서버가 프로그램을 실행해 응답을 만드는가

아무 숫자나 넣어 보세요. 답은 이 페이지에 없고, 누를 때마다 서버가 adder 프로그램을 실행해서 만듭니다.

GET (값이 주소에 붙음): +
POST (값이 본문에 담김): +

GET은 결과 페이지 주소창에 ?a=..&b=..가 보이고, POST는 주소창에 값이 없습니다.

3 오류: 없는 파일을 404로 알려주는가

/nope.html → Network 탭에 404, 화면에 "Tiny couldn't find this file"

403, 413, 502, 504처럼 브라우저로 만들기 어려운 오류는 터미널에서 curl, nc로 보여줍니다.
